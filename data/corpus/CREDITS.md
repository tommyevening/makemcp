# Blueprint corpus — sources & attribution

The JSON blueprints in this folder are used to mine Make module schemas (each
exported blueprint embeds its modules' parameter/expect schemas and real mapper
values). They are publicly shared, importable Make/Integromat blueprints
collected from community sources for interoperability/educational purposes.

| File(s) | Source |
|---|---|
| `okash1n-sample.json` | https://github.com/okash1n/make-blueprints |
| `felores-*.json` | https://github.com/felores/make-blueprints |
| `elyf-*.json` | https://github.com/ely-fornoville/integromat-blueprints |
| `rish-*.json` | https://github.com/rish404/make-blueprints |

If you are an author and want a blueprint removed or re-attributed, please open
an issue. When adding your own blueprints, please add a row here (or note that
they are your own work).
